Manage oars and collections

Inspect saved oars and pairs, retain calibration history, and organize independent managed copies for a crew or club.

Choose the right record

Open Oar Settings → Manage Oars. The list includes saved oars and named pairs as well as independent managed oars and collections. Opening a detail view does not change the selected rowing connection.

Editing a saved oar updates that saved record. A managed copy has its own details and history. Use Copy to managed oars from a saved oar, or Copy from saved oars or calibrations, when you want an independent managed record.

  1. Use New oar or copy an existing setup.
  2. Check the name, side, type, model and intended sensor pair.
  3. Choose or attach the saved alignment and stiffness calibration.
  4. Enter current dimensions and review the Moment/Bend Factor preview and its source.
  5. Use New collection to group oars for a boat, crew or club.

Choose the oars for your next row in Connect Oar.

Measure and maintain an oar

A managed oar’s details offer Create alignment and Perform stiffness calibration. Use Edit to adjust its details or choose saved components. A saved oar’s details use Edit oar details; use the selected oar in Oar Settings for alignment and stiffness measurement.

Current dimensions may differ from those at the original calibration. Reuse Cperm for the same shaft with suitable geometry and shaft-profile information; use a new measurement when the changed setup is not covered. The original alignment and calibration records retain their measurement history.

A manual MBF uses the entered factor directly; a manual Cperm still needs current dimensions. Saving a new measured stiffness calibration selects its Cperm and clears both manual overrides. Check the saved sensor pair, alignment, calibration and active factor before using the setup.

Share or import a collection

  1. For an individual record, choose Share oar and calibrations. For a collection, use Share collection. The full export action is Share managed oars and sensor calibrations.
  2. Send the resulting JSON file using Mail, Messages or AirDrop.
  3. On the receiving phone, save it to Files.
  4. In Manage Oars, choose Import managed oars, select the file, review its contents and tap Import copies.

Existing oars are kept. Imported copies are not selected for a workout automatically. Saved-oar sharing includes the chosen setup; an independent managed copy can preserve the fuller alignment and stiffness history.

The Saved oar collections — import / share tools handle saved-oar collections. Check the destination and selected records before importing. Managed-oar JSON, view/settings share text, calibration CSV and printable QR labels have different purposes.

Print and use an oar label

In the calibration tools, choose Print oar labels and use the print or Share PDF action. A label can carry oar details and selected alignment/stiffness values.

Use Scan oar label in the connection workflow. Verify that the label describes the physical shaft, sensors and mounting positions now fitted to the oar.

Before using a shared setup

Check the exact shaft, sensor pair, positions, side, inboard/outboard, selected calibration and active override. A shared record cannot verify the current mounting. Repeat alignment after moving or replacing a sensor.
