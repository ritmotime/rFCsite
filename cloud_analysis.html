From the iOS app

The app records oar sensor data with its alignment already applied. Send the workout package and its settings; the server uses those aligned readings without applying a second mounting alignment.

The alignment recorded with the workout is the relevant one. A newer alignment applies to future recordings.

From Android

Use WitMotion to make one short alignment recording, then a separate rowing recording. Upload both TXT files the first time; use the same account to reuse your saved alignment on later workouts.

Choose your comparison

Pieces are continuous stretches of rowing. Stroke groups collect similar strokes from anywhere in the workout. They are separate views of the same session.

Workout Settings includes clustering controls. Start with 5 target groups, 2 strokes/min minimum rate separation, and equal weights for rate, handle peak rotation speed and power. Features are scaled before they are combined, so their different units do not dominate. Fewer groups may be appropriate for a steady workout.

Change the target count, rate separation or weights when you want a different comparison. These settings change group membership, not your recorded motion or piece boundaries.

Change your settings. Run it again.

Review and change the input and workout settings for another server analysis—including rowing side, boating setup, Moment/Bend Factor, piece detection and stroke-group controls. Open the workout’s Re-analyze controls, edit the settings and generate a new report.

Re-analysis uses the saved upload while it is retained. Keep a copy of your original recording so you can upload it again later. For app recordings, changes apply to the recorded, already-aligned data.

Read, compare, download

  • Open averaged moment and motion curves for pieces or stroke groups, with optional stroke variability shading.
  • Use the session overview to compare stroke metrics over time.
  • Choose the All Strokes columns you want, then download CSV data for strokes, pieces, groups or averaged curves.
  • Download the self-contained HTML report to open it locally without a running analysis server.

Settings marked HTML adjustable can be changed in the downloaded report itself. Changes to analysis settings are made on the server when you run the workout again.

Check the source: the report records which alignment was used and flags setup differences. If Android data has no usable saved or uploaded alignment, it is processed using raw axes. GPS and heart rate appear when supplied; missing telemetry is not invented.
