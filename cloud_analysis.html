Cloud Analysis

Cloud Analysis turns workout motion data from the mobile app into an interactive, shareable HTML report.

Getting started

Record a workout in the RitmoForceCurve mobile app, then open Cloud Analysis to upload the workout data and queue the analysis. When the analysis is finished, the report can be opened in a browser and shared as an HTML file.

The report groups and averages strokes by rate, power, stroke length, and handle speed so you can review how the workout changed across pieces and intensity levels.
