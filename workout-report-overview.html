Your first look

Section link
  1. Unzip the download if needed, then open the .html file in Safari or Chrome. A file preview may show only a static summary.
  2. Open Session Overview to see the workout over time. Choose useful metrics such as rate, power and speed, where available.
  3. Select an effort, then open Boat & Oar Motion curves to compare averages or inspect individual strokes.

The examples below show control labels; they do not operate a workout. Older reports and focused exports can have different labels or fewer sections.

Explore the session and map

Section link

In Session Overview, narrow the time window using the range bar below the plot. Move across the plot, or along the GPS route, to inspect matching times and values. Drag away from the route to pan the map; use its zoom controls to get closer.

Use the shared piece/group selection to focus the linked views. All strokes restores the full retained workout selection. Map backgrounds need internet; GPS gaps remain gaps.

Compare efforts, then inspect a stroke

Section link

In Boat & Oar Motion curves, select the pieces or groups you want to compare. The average view shows a mean curve for each comparison. Switch to Individual strokes to inspect the variation. The selected oar, curve choices and scales carry across, so you can compare the same signal in both views.

For a custom comparison, open Create groups, choose the source strokes and grouping method, then Preview groups and Create selected averages. Groups can combine strokes from different times. Read any availability note: a browser-created average depends on the samples retained in the report.

Choose and read your curves

Section link

Use Find motion curves to locate a signal. Choose Core for a shorter list, or Advanced and Diagnostics for additional choices. Check the X-axis label: time and sweep angle answer different questions.

In reports made with the updated test processor, Core includes S1 and S2 body-Z gyro (GZ), each sensor’s original sweep speed (RZ), and signed bend and moment. Choose the signed curves to inspect available samples before catch and after finish.

Drag horizontally on the curve plot to zoom into part of the stroke. Hover to read each curve in its own units. Curves have independent scales, so equal screen heights need not mean equal values. Scale and Shift change the display, not the recorded measurements.

Connect the curves to the movement

Section link

Pause the animation and use Time relative to catch to move within the current stroke. Click the curve plot to follow the pointer; click again or press Escape to hold the view.

Drag the animation to rotate the scene and scroll to zoom. On touch screens, use one finger to rotate and two fingers to pinch or pan. Reset view restores the camera. The animation illustrates available measurements and assumptions; it is not a video recording.

Save a view you like

Section link
  1. Choose your curves, scales and layout.
  2. Open Choose / create config, enter a name and select Save new. To retrieve it later, choose the configuration and select Apply.
  3. Select Download configured HTML to keep a report file that opens with your view.

Saving in the browser does not overwrite the original HTML file. To transfer just the settings to another workout, use Download config file and Import config under Import / export · settings only.

Share a report, picture or numbers

Section link
  • Interactive report: use Share workout. Choose the full report or a focused view, then the pieces/strokes and opening view to include.
  • Picture: use Download plot image for a static image of the current view.
  • Numbers: choose the relevant CSV export, such as Download shown curves CSV or Download GPS CSV. Check the exported headers for units.

A focused export contains only the included data. Share the HTML with someone who should have access to that workout and its included GPS route.

If something looks missing

Section link
  • No working controls? Open the actual HTML in a browser, outside the file preview.
  • A curve disappeared? Check the selected strokes, chosen curves, Scale and Shift.
  • A choice is unavailable? Read its availability note. A display change cannot restore missing recordings or samples omitted from the file.

For missing recordings, sensor interruptions or setup checks, see recording and data troubleshooting. For measurement definitions, use the metric reference. For help getting a report, see Upload & analyze a workout.
