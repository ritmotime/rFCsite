Share views and workout settings

  1. Open Share / Import Views / Settings → Share Views / Settings.
  2. Select the views and whether to include workout settings. Add a naming prefix if offered.
  3. Tap Generate Share Text, then Share or Copy to Clipboard.

On the other phone, open Import Views / Settings, paste the text and tap Read Import Text. Review the preview and choose whether to import views, settings and activate the imported views.

Check the resulting screens and thresholds before rowing. A shared layout cannot supply an unconnected sensor or missing recording.

Share managed oars or a crew collection

  1. In Manage oars, open a collection and choose Share collection, or use Share all managed oars.
  2. Send the JSON file. The recipient saves it to Files.
  3. On the receiving phone, choose Import managed oars, select the JSON file and review the oars and collections.
  4. Tap Import copies.

Existing oars remain intact. The imported collection stays in Manage oars; it is not selected for a workout automatically. Its saved alignment/calibration components and current dimensions can be reviewed independently.

Check a saved calibration or QR label

A label can carry the oar details and saved calibration/alignment. Use Scan oar label in the connection workflow, then check that the physical shaft, sensor pair and mounting positions match. Calibration CSV exports and label files are distinct from managed-oar JSON and view/settings share text.

Before recording, verify side, type, dimensions, selected calibration and Moment/Bend Factor (N·m/°). A manual MBF override takes priority; manual Cperm uses the dimensions. Re-align after moving or replacing a sensor.

Share a workout’s results

A whole-workout upload includes available oar, phone, watch and GPS data, plus the setup captured with that recording. New recordings also retain oar acceleration and fresh magnetic data when recorded, and preserve dimensions even with a manual factor.

The server shows the original snapshot under Recorded oar settings. Analysis overrides do not overwrite it. After processing, download the interactive HTML report and available exports.
