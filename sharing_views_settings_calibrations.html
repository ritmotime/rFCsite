Share views and workout settings

  1. On Home, open Share & Import → Share Views / Settings.
  2. Select the views and whether to include workout settings. Add a naming prefix if useful.
  3. Tap Generate Share Text, then Share or Copy to Clipboard.

On the other phone, open Share & Import → Import Views / Settings, paste the text and tap Read Import Text. Review the preview and choose whether to import views, settings and make imported views active. Resolve any name conflicts, then tap Import.

Check the resulting screens and thresholds before rowing. A shared layout cannot supply an unconnected sensor or missing recording.

Share oars or a crew collection

  1. In Manage Oars, use Share oar and calibrations for a single record, Share collection for a collection, or Share managed oars and sensor calibrations for the full managed export.
  2. Send the JSON file. The recipient saves it to Files.
  3. On the receiving phone, choose Import managed oars, select the JSON file and review the oars and collections.
  4. Tap Import copies.

Existing oars remain intact. Imported managed copies are not selected for a workout automatically. Review their alignment, stiffness components, history and current dimensions before choosing a rowing setup. Saved-oar collections have their own Saved oar collections — import / share tools.

Check a saved calibration or QR label

Use Print oar labels in the calibration tools to print or share a label PDF. A label can carry oar details and selected calibration/alignment. Use Scan oar label in the connection workflow, then check that the physical shaft, sensor pair and mounting positions match. Calibration CSV exports and label files are distinct from managed-oar JSON and view/settings share text.

Before recording, verify side, type, dimensions, selected calibration and Moment/Bend Factor (N·m/°). An enabled manual MBF takes priority; manual Cperm uses current dimensions. Saving a new measured stiffness calibration selects its Cperm and clears both manual overrides. Re-align after moving or replacing a sensor.

Reuse a report layout

The completed report provides its own view and preset controls for reusing a layout. A preset carries view choices; each report still uses its own recorded data.

Share a workout’s results

A whole-workout upload includes available oar, phone, watch and GPS data, plus the setup captured with that recording. New recordings retain oar acceleration and preserve dimensions even with a manual factor.

The server shows the original snapshot under Recorded oar settings. Analysis overrides do not overwrite it. After processing, download the report ZIP and extract it to open the interactive HTML report. CSV exports provide the available stroke and summary data.
