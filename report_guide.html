Start with a useful comparison

  1. In Session Overview, choose rate and power; add GPS pace or heart rate if recorded.
  2. Zoom a period with the bar below the chart. Create a named group from the visible strokes.
  3. Open Boat & Oar → Averaged curves to compare that group with another part of the row, an automatic group or a piece.
  4. Switch to Individual strokes to inspect one stroke at a time, or play the selected strokes in sequence.

Searching the stroke table does not redefine averages. Make a selected group when you want a different set of strokes to determine a comparison.

Compare the full stroke and recovery

Click Show stroke checks in Session Overview to plot the three values, or in All Strokes to show their columns with stroke ID and time. They are also included in the workout, group and piece summaries and the selected individual stroke’s metric panel. You can still choose them individually under GPS.

Distance check, Speed check and Energy-loss check (V²) are Core choices. Each compares the full catch-to-catch fused-speed profile with steady travel at that cycle’s time-weighted mean speed.

Distance check is the range of accumulated relative position in centimetres. Speed check is the relative-speed range in metres per second. Energy-loss check is 100 × (oscillating V² integral − steady V² integral) / steady V² integral. It is a V² model of speed variation, not a measured percentage of rowing energy lost.

Only complete cycles with supported fused speed contribute. Piece, group and workout summaries show Average distance check, Average speed check and Average energy-loss check: the arithmetic means of valid member-stroke values. Each valid stroke has equal weight; the checks are never summed. Workout averages use member strokes directly, rather than equally averaging differently sized pieces. The separate IMU Speed swing and Surge excursion metrics keep their original meaning.

If no valid cycle is present, the check remains selectable and shows unavailable with the need for supported GPS + phone motion. A valid measured zero is shown as zero. The checks are scalar metrics; inspect their changing input with the Fused boat speed (GPS + IMU) curve.

For a saved iOS workout, open Workout Metrics → Recalculate boat checks. The app uses that workout’s original native phone/GPS files and saved settings, updates the supported checks, and preserves the other stroke metrics. A missing source file or unsupported cycle stays unavailable. Open All Stroke Metrics in the same section to inspect individual values.

The three checks are placed first in the workout summary and near the start of All Strokes. Workout and individual-stroke values wrap on narrow screens. The static preview also includes the checks when a viewer cannot run JavaScript; interactive curves and downloads require opening the HTML in a browser.

Arrange the boat and curves

Use Layout in Boat & Oar to choose Side by side, Animation above curves, Curves above animation, Animation only or Curves only. Layout changes preserve the selection and playback position. On small screens, the workspace stacks.

Playback, View and water, Motion exaggeration, Measurements and Downloads expand independently below the animation. Curve selections and scale controls can also collapse.

Click a curve plot once to make the animation follow the pointer. Click again or press Escape to freeze the pose. Use Hide animation to give the curves more room.

Play consecutive strokes

  1. Choose Play consecutive strokes, or open Individual strokes.
  2. Select a piece, group or stroke range beside the individual plot.
  3. Leave Continue through selected strokes enabled and press Play selected strokes.
  4. The animation and curve advance together. Disable continuation to repeat one stroke.

Playback respects the selected membership and recorded gaps. Strokes selected from separate parts of the workout are not presented as continuous recorded time. For group comparisons, return to Averaged curves.

Make curves easy to compare

  • Choose time or sweep angle. Time locates events in seconds; angle locates them along the oar’s sweep. Drive and recovery remain distinct.
  • Choose the phase and catch position. Show drive, recovery or both where supported; use Catch left, Catch center or the position control.
  • Adjust each metric’s range and position. Auto fits relevant visible data; All uses the broader range. Hover labels retain the metric’s own units.
  • Keep scales steady between strokes. Use Fit this stroke for a closer look or Reset plot to restore the initial view.

Equal screen height does not mean equal physical magnitude. Fused boat speed retains absolute ground-speed values; its reference line can show the complete-cycle mean rather than zero.

Understand averages and stored detail

Original server group and piece averages use the full analytical samples. Strokes are compared at matching elapsed times or sweep positions; their durations are not stretched to make every endpoint coincide. The number of contributors can change along a curve.

Groups created in the browser use individual traces stored in that HTML. Their averages can be approximate when individual curve detail has been reduced, while their metrics use the stored analytical results. Show variability describes stroke-to-stroke spread, not sensor accuracy. Density shading shows sample overlap where included.

Optional individual-sensor GZ diagnostics are available only as preset group/piece averages. The HTML does not store individual sensor GZ traces, so it cannot make new user-group GZ averages or member overlays for them. The ordinary oar-speed curve remains available.

Read the route and replay in context

The GPS track can follow a selected group or the visible session strokes. Choose a metric for colour, then zoom or pan. Map backgrounds require internet access and coverage varies. GPS gaps remain gaps; ground speed is affected by current.

The animation is a hull-and-blade model driven by available data. Use exaggeration to see small movements, then return to 1× to judge their size. A second displayed oar can be mirrored from one recording.

Show blade slip trail adds a dashed inner trail at the nearest submerged blade edge or wet shaft centreline. It responds to the waterline, depth, feather and hull motion. It illustrates assumed geometry; it does not measure actual blade immersion or water speed.

Adjust calibration and export results

A report factor change rescales moment and effort-derived values while preserving stroke angles, timing and rotation speed. Original pieces, groups and smoothing response remain fixed. Reset restores the generated factor. Re-analyse to rerun detection or grouping under different processing settings.

Smooth joins adjusts recovery only for display. Animation averages may register recovery duration while retaining drive timing. These choices do not change stored workout metrics.

  • Summary and averaged-curve CSVs: keep the comparison with the active factor where supported.
  • All Strokes CSV: exports displayed rowing metrics; choose columns first.
  • Shown-curves CSV: exports the selected individual curves and units.
  • PNG/JPEG: saves the current plot and legend.
  • Download animation HTML: keeps a standalone replay of selected content where offered.

Named groups and browser adjustments are temporary in the open report. Download the results you want to retain. Numeric CSV time and PowerSplit values use seconds even when the screen formats minutes and seconds.

The included example has the restored curve and metric controls. Its recorded inputs still come from the source workout; controls cannot add samples that were never saved. Your own saved HTML reports keep the data and controls of the version that generated them. Re-analyse the original workout to apply new processing.
