Use this tab after the sensors are mounted and connected. It displays the sensor gravity angle so you can adjust the sensors before rowing.

What this tab does

Mnt Ang check is a sensor-mounting check. It is separate from oar calibration and does not calculate or save Scale Factor.

  1. Connect both oar sensors.
  2. Open Sensor Mount / Oar Calibration.
  3. Choose Mnt Ang check.
  4. Select Port or Starboard so the displayed angle is oriented correctly for the side you are checking.
  5. Adjust the mounted sensors while watching the displayed angle values.
  6. Use Store Mac addresses of connected sensors when you want the app to remember the connected sensors and their stored mount angles.
The Port/Starboard selector on this tab is only for this mount-angle display. It changes the display orientation from about 180 toward zero. It does not save the active calibration, does not change workout settings, and does not set Port/Starboard for rowing.

When to use it

  • After attaching sensors to an oar for the first time.
  • After moving sensors or replacing straps/pads.
  • Any time the sensors may have rotated on the shaft.
